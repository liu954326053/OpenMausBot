## 1. 改名

**改：**

- README、`docs/`、`DESIGN.md`、`CONTRIBUTING.md` 等文档，代码注释，界面文字，脚本和工作流里给人看的文字里的 `OpenMausBot`。
- 文档里指向现在这个应用的名字：`/Applications/OpenMausBot.app`、安装包名 `OpenMausBot-…`。
- 自己仓库的地址：`electron-builder.yml` 的 `repo`、`server/update-check.ts` 的两个地址。

**不改，改了会坏：**

- 上游仓库的地址（`milind-soni/OpenMausBot`、`Prudctual/OpenMausBot`）和它的下载文件名。
- 读旧版数据的代码和说明它的注释：`shared/former-name.ts`、同时认两个名字的正则、旧版的数据文件夹路径、`openmausbot://` 链接。
- 应用之间通信用的名字：`X-OpenMausBot-*` 请求头。
- 第三方代码的许可声明，旧格式的测试样本，检查"不许再用旧名字"的词汇测试。
- 小写的 `openmausbot`：npm 包名、命令、域名、协议路径、存储键。这次不动。
- 本机路径 `OpenMausBot-wt`、`OpenMausBot-lab`，以及这个仓库在磁盘上的文件夹名。

**需要仓库主人做的事：** 在 GitHub 上把 `liu954326053/OpenMausBot` 改名成 `MagicBot`。在那之前，已安装的应用检查更新会找不到地址。

## 2. 收件箱

- 只在高级模式、宽侧栏里移动。顶部那一行从左到右：收件箱、空白、"这台电脑"、加号。
- 样子：图标、"收件箱"三个字、有待处理时的数字。有机器人在干活时图标角上有绿点。行太窄时只留图标和数字。
- 点一下打开收件箱，再点一下关上，和原来一样。
- 列表里原来的那一行去掉，不留两个。
- 简单模式不动：桌面应用里那一行被主机器人的卡片占着，没有"这台电脑"。窄图标栏和手机也不动。

## 3. 新建项目

- 整行宽的实心主按钮（`.ui-button .ui-button-primary`），加号图标加"新建项目"。
- 位置：项目模块的最上面，也就是主机器人下方。
- 搜索时、以及这个应用在操控另一台电脑时不显示，和原来一样。
- 窄图标栏里的加号不动。

## 4. 项目列表

- 有项目时，按钮下方出现一行小字"项目列表"（英文 "Projects"），12px、中等字重、第三级墨色。
- 项目行和它下面的提示整体向右缩进 12px。
- 没有项目时不出现这行字，只有按钮。
- 窄图标栏不动。
