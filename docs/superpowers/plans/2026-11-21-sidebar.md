# 左侧和团队地图：实现计划（sidebar 轨道）

日期：2026-11-21 · 设计：`docs/superpowers/specs/2026-11-21-teams-flow-project-canvas-design.md` 第 3 节，加上第 1 块留下的三件事

**目标：** 左侧只剩主机器人、收件箱、项目列表、新建项目和底部工具；项目一行一个，点开是项目视图；部门、项目外的机器人和群聊都在团队地图上管理和打开；项目外有未读时，团队地图入口上有一个点。

**做法：** 左侧的分区、置顶、拖动整块拿掉，项目从"分区"改成"行"。项目视图先做一个能用的过渡版本（负责人、成员、各自状态、打开对话），组件的接口按约定定死，整合时换成画布。团队地图在自己的文件里加东西，热点文件只加接线。

## 这一块定下的细节

### 左侧，从上到下

1. **主机器人**：本人的 MagicBot（`myDefaultBot`），在左侧隐藏了（"在左侧显示 MagicBot"关掉）就不显示。Simple 桌面上仍是那张大卡片；Advanced 是普通的机器人行，保留它的对话列表；图标模式是头像；手机上是原来的大卡片。
2. **收件箱**：现有的收件箱行，挪到主机器人下面。服务器不支持收件箱时，原来的"需要你"按钮放在同一位置。
3. **项目列表**：一行一个项目，点行打开项目画布；没有展开箭头，行下面不列成员，搜索时也一样。行上一直有一个状态点（等你 > 未读 > 在干活，和现有的分区状态点同一套），算的是项目里所有的机器人和群聊。保留第 1 块的"团队有变化"提示（在行下面）、"项目文件夹不在了"提示，菜单里有"查看团队变化…"和"归档"。图标模式里每个项目是一个方块（项目名首字）。
4. **新建项目**：在项目列表最后，服务器没有项目功能时不显示（和现在一样）。
5. **底部工具**：不变，只多一个点（见下）。

拿掉：部门、机器人、群聊、机器人对话、已置顶（置顶的机器人、置顶的对话、圆形置顶和它的对话列表）、"进行中"分区。Team Cloud 上的"只看我/团队"开关和成员列表不是这几类，保留；跨地方的机器人行（Together、已搬走）也保留。

### 拿掉的分区里原来的功能去哪

- **搜索**：只搜项目。框里写"搜索项目"；按项目名找，不分大小写，留下的项目还是一行，下面不列东西，点了打开画布；一个都对不上时显示一行浅色的"没有与「…」匹配的项目"。主机器人和收件箱照常显示，不参与过滤。项目里的成员、项目外的机器人和群聊、别处的机器人和消息结果都不在左侧列出；⌘K 照常能找到任何机器人、群聊和消息。
- **"进行中"分区**：拿掉。收件箱里的"进行中"还在；收件箱和老服务器的"进行中"弹层里"固定到左侧"的按钮一起拿掉（没有地方可固定了）。
- **置顶的对话**：左侧不再显示，收件箱里的"置顶"列表还在。机器人菜单里的"置顶/取消置顶"拿掉，外观设置里"圆形置顶""置顶在所有地方"两项拿掉（它们只管左侧的置顶）。服务器的 `pinned` 字段不动。
- **部门之间拖动**：左侧拿掉（机器人、群聊、分区的拖动和 Alt+↑/↓ 排序）。团队地图上拖动机器人换部门、Alt+↑/↓ 排卡片照旧。主机器人的对话文件夹拖动照旧。
- **部门菜单**：标记已读、暂停部门、批量设置、分享部门搬到团队地图上每个团队的菜单里（说明、记忆、改名、删除原来就在）。
- **键盘**：⌘1–9 和 ⌘⇧[ / ] 照旧读左侧显示的机器人行，现在只有主机器人；按下打开它的对话。别的机器人用 ⌘K 或团队地图打开。⌘N 新建机器人，和"+"里一样落到团队地图。
- **新手引导**：步骤指向输入框、模型、电脑、底部工具、应用、自动化，没有指向拿掉的分区，不用改。
- **"+"里其余几项**：新建群聊搬到团队地图的群聊列表；团队库和导入搬到团队地图的"添加"菜单；Advanced 的"新对话"面板和 Simple 的"和 {name} 开始新对话"拿掉（对话里 ⋯ 菜单和机器人面板里都能开新对话）；已归档的机器人在底部账户菜单里本来就有。

### 顶部"+"

只剩三项：新建项目、创建机器人、创建部门（按现有权限显示）。建好机器人或部门后打开团队地图，把它挪到视野中间并高亮一下（机器人用现有的"刚发送"边框，部门用同样的边框）。⌘N 一样。

### 项目视图

- `src/components/project-view/ProjectView.tsx`，`{ projectId: string; selectedBotId?: string }`，按约定不改。
- 状态：`activeView` 多一个 `"project"`，`state.project = { id, botId? }`，动作 `{ type: "showProject"; projectId; botId? }`。打开任何对话、团队地图或别的页面就离开项目视图。
- 过渡版本：项目名、文件夹路径；负责人在前、成员在后，每个一行（头像、名字、职责、状态：等你、在干活、未读），每行有"打开对话"；选中的成员高亮并滚到视野里；项目自己的群聊也列出来，点了打开（项目外的群聊在团队地图上，项目里的群聊总得有地方打开）。
- 项目不在了（归档、删除）：打开主机器人。

### 打开什么

- **启动时**：上次停在项目视图且那个项目还在，就回到项目视图；否则和现在一样打开上次的对话，没有就打开主机器人（左侧不显示主机器人时打开第一个机器人，它可能不在左侧）。记在本机（`openmausbot.lastProject.v1`）。测试实例的 `ui launch` 把 Pepper 记成上次的对话，所以照旧从 Pepper 开始。
- **选中的机器人或群聊不在了**（删除、归档）：打开主机器人；没有主机器人时和现在一样打开剩下的第一个。
- **打开的项目不在了**：打开主机器人。从左侧归档项目时也一样（现有逻辑）。

### 团队地图

- 项目的团队不显示：项目里的机器人、项目的部门都不画（`teamProjectSide.of` / `department`）。所以项目部门的共享说明在界面上没有任何入口（只有团队地图提供过，左侧的部门菜单没有）。
- "添加"菜单：创建机器人（和左侧同一个 `newBot`）、创建团队（原有）、团队库、导入、云电脑、本地虚拟机。建好后同样挪到视野中间。
- 每个团队的标题下写不能用来建项目的原因，来自 `/api/team-projects/teams`：`no_chief`"还没有负责人"、`empty`"还没有机器人"、`main_bot_chief`"负责人是 MagicBot"。完整句子（新建项目窗口里那句）作为说明给读屏和悬停。
- 机器人卡片：有未读时名字旁边一个强调色的点。
- 主机器人：拖到部门上时不显示可放下，松手也不移动，状态行说明"MagicBot 不属于任何部门"；服务器拒绝时照旧显示在顶部的错误条里。
- 群聊：底部多一个"群聊"列表（和"谁在交接"同样的折叠条），列出项目外的群聊和机器人对话，有未读的带点，点了打开；"新建群聊"也在这里。

### 项目外的未读

项目外的机器人（不含左侧显示的主机器人）或项目外的群聊有未读时：Advanced 和图标模式底部工具里的"团队地图"一行有一个强调色的点（工具分区收起时分区标题也有）；Simple 的账户菜单里"团队地图"一项有点，账户头像上也有点；手机的工具菜单同样。需要人做的事（审批、提问）照旧进收件箱。

### 第 1 块留下的

- 项目部门的共享说明：见上，团队地图不显示项目的团队后，界面上没有入口。
- 分身的单个对话模型选择器：对话顶部和失败行里的模型选择器换成只读的模型名，点开说明"跟随 {team} 的 {source}"和"它的名字、职责、说明、外观和模型来自 {source}"，有"打开 {source}"。
- 团队不能用的原因：团队地图上照上面显示。

## 设计没定、这里定了的

1. 项目行的状态点算项目里所有的机器人和群聊，搜索时也一样。
2. 图标模式里每个项目只有方块和状态点。
3. 左侧的搜索只看项目名；项目外的机器人和群聊在团队地图和 ⌘K 里找。
4. 项目视图过渡版本也列项目自己的群聊。
5. ⌘1–9 打开机器人的对话，不打开项目视图。
6. 部门菜单里的标记已读、暂停、批量设置、分享搬到团队地图的团队菜单。
7. "+"里的新建群聊、团队库、导入搬到团队地图；新对话面板拿掉。
8. Team Cloud 的成员列表和"只看我/团队"开关保留。
9. 团队不能用的原因在团队地图上用短句，完整句子做说明。
10. 搜索时主机器人和收件箱照常显示，不参与过滤。
11. 没有项目对得上时用自己的一句（`sidebar.noProjectMatch`），不用 ⌘K 的 `sidebar.noMatch`。
