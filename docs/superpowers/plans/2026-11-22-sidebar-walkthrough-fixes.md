# 走查后的设置和左侧修复：实现计划（sidebar 轨道）

日期：2026-11-22 · 依据：`main` `529c9f121` 的走查报告里分给 sidebar 的五件事

## 五件事和做法

1. **Simple 模式里找得到已归档的项目（07-05～07-08）**
   - 设置的"数据"页在 Simple 里也列出，条件是这台服务器有项目（项目列表读到了）；Simple 里这一页只有"项目"和"已归档的项目"两组。存储、对话清理、活动记录仍只在 Advanced 里，搜到它们或链接到它们时照旧打开 Advanced。
   - `SettingsContext` 多一个 `projects`；数据页的 `when` 改成"管理员，并且 Advanced 或有项目"；`ADVANCED_PAGES` 去掉 `data`，`storage`、`activity` 两条标成 `advanced`；重新生成 `shared/settings-places.ts`。
   - 打开数据页、项目根目录、已归档的项目都不再切到 Advanced，"设置 → 数据"的撤销失败提示和空状态文字在两种模式里都成立。
2. **中文界面里不再出现 "New thread"（04-07、09-01、09-03）**
   - 每个显示对话标题的地方都过一遍 `localizedTaskTitle`：收件箱（置顶、已完成、进行中的行、消息行的出处、阅读页、搜索）、⌘K 的消息结果、对话选择器、自动化的结果去处、记忆的来源、团队地图卡片上的"正在做"、对话卡片的提示。
   - 左侧的消息搜索结果随 flow 的"只搜项目"一起拿掉，不另改。
3. **项目文件夹不见了，马上显示（07-10～07-14）**
   - 服务器：`server/team-projects/` 里每 2 秒用异步 `stat` 看一遍每个项目的文件夹，状态变了才通知：发一个只给管理员的 `{ kind: "team-projects" }` 实时事件，并让项目画布发一次 `project-canvas` 事件，打开着的画布重读快照。
   - 客户端：`src/state/team-projects.ts` 收到 `team-projects` 事件就在后台重读列表，左侧的提示不用刷新就出现、消失。画布头部的文字由 canvas-client 换成左侧的那句。
4. **归档的撤销提示不挡输入框（07-03）**：`UndoToast` 加一个放在左下角的位置（和 `NoticeToast` 同一处），归档项目的撤销用它。
5. **打开项目副本的对话时选中项目行（05-02、09-10）**：左侧按打开的机器人找到它的项目（`side.of`），那一行显示为选中。

## 顺序

先做 1、2 和 3 的服务器部分；flow 落地后合并 `main`，再改左侧的文件（5、3 的客户端、4）。每件事配单元或 DOM 测试；最后在 UI 锁下只跑涉及的 UI 套件，截中文浅色和深色图到 `/tmp/omb-walkthrough/fixes/`。
