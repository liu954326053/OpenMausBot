# 制作看板：实现计划（pb-board 轨道）

日期：2026-11-24 · 依据：`docs/superpowers/specs/2026-11-24-production-board-design.md` 第 4 节、`BOARD-CHARTER.md`、效果图 index-v5

## 做法

1. **看板模型**（`src/lib/production-board/`，纯 TypeScript，先写测试）
   - `cards.ts`：从 `CanvasSnapshot` 得出卡片：bot、需求单、任务拆分、分集、分集摞、角色、场景、镜头、结果、成片、其他；每张卡带它代表的节点 id（角色、场景是整个组；结果是镜头的 creation 加全部 take）。旧项目的 `script` 当 EP01，没有 `episode` 的镜头当 EP01；没有计划也没有内容时只有负责人卡和提示。有计划时，分镜和后期的"源 bot"不画，只画每集的副本。
   - `edges.ts`：六种连线 × 三种状态、第 4.2 节的标签（标签是数据，界面再 `t()`）；引用线默认隐藏，开关打开、悬停或选中相关卡时显示。
   - `stages.ts`：五个阶段的状态（等待 / 进行中 / 完成 / 失败）。
   - `fold.ts`：进行中、失败的集和人点开的集展开，其余进一张分集摞。
   - `layout.ts`：五条阶段带从左到右；每个展开的集一条横道（分镜师 → 细化场景和镜头 → 结果 → 后期 → 成片）；角色在上、场景在下；其他卡排在最下面。卡片尺寸固定，先用自己的占位尺寸，合并 `wt/pb-cards` 后用 `BOARD_CARD_SIZES`。人拖过的卡按存下的位置画。
   - `camera.ts`：适应、缩放、视口裁剪、远景阈值。
2. **服务端补两项**（`shared/project-canvas.ts` 最小改动，`server/project-canvas/` 带测试）
   - `CanvasNode.arranged?: true`：人移动过节点（含 bot 节点）时服务端记下，看板才分得清"人拖过的位置"和服务端默认摆放的位置；旧画布上的位置不算。
   - `CanvasBotState.steps?`：bot 最近几步（活动行的文字和时间），供 bot 卡的"最近几步"。写进状态文件告诉 `pb-cards`。
3. **看板界面**（`src/components/production-board/` 顶层和 `board/`）：相机（拖空白平移、滚轮和捏合缩放、键盘、适应）、只画视口内的卡、SVG 连线和标签、顶部阶段条、小地图、远景标签、引用线开关、拖卡片（`applyOps` 的 `update_node` 位置）；先画占位方框，合并 `wt/pb-cards` 后换成它的卡片。
4. **浮层插槽**：看板接 `overlay?: ComponentType<BoardOverlayProps>`，在视口上层画它，持有 `opened`，点 bot 卡开对话、点其他卡开详情，实现 `anchorOf`、`subscribeView`、`focusNode`、`focusEpisode`、`focusStage`。`pb-panels` 完成时合并并接进 `ServerProjectCanvas.tsx` 和预览。
5. **替换旧编辑器**：项目视图的画布模式显示看板；新建节点、连线、分组、上传、撤销重做、删除、节点面板、旧的运行条和 `answerVideos` 都删掉；`ProjectSettingsDialog` 照旧打开；归档只读、文件夹丢失照旧。删前用 `git grep` 查别的分支。
6. **后端**：加 `retry`（`{ job }` 或 `{ episode }`）和每集的 `readTimeline`；去掉 `answerVideos`；其余照旧。内存后端同样实现。
7. **动作**：生成（`startGeneration`）、播放、选用版本（`selectTake`）、重试。
8. **样例、预览、UI 测试**：`src/testing/production-board-sample.ts`（60 集、3 集进行中、4 角色、4 场景、带 take 的镜头、一个生成中、一个失败、一个成片）；预览和 `project-canvas-ui.e2e.test.ts` 改成看板；删 `pipeline-run-ui.e2e.test.ts`；UI 锁下截两种皮肤、正常和小窗口的图到 `/tmp/omb-wt-pb-board/`，量 60 集样例的渲染和平移耗时。

## 顺序

计划 → 模型和布局（带测试）→ 方框版看板、相机、拖动、浮层插槽 → 替换旧编辑器、修失败的文件 → 服务端两项 → 合并 `wt/pb-cards` 挂卡片 → 连线、标签、阶段条、小地图、远景 → 动作 → 预览、UI 测试、截图。每一步提交一次。
