# 制作看板的浮层：实现计划（pb-panels 线）

日期：2026-11-24 · 设计：`docs/superpowers/specs/2026-11-24-production-board-design.md` 第 5 节

**目标：** 看板上面那一层：右侧悬浮、可展开收起的三栏面板（团队 / 素材分类 / 分集），贴在 bot 卡旁边的对话窗，素材的只读详情和"让某人调整"。

**做法：** 只实现 `src/lib/production-board/overlay.ts` 的约定：导出 `ProductionBoardOverlay(props: BoardOverlayProps)`。所有数据来自 `snapshot`（`bots`、`nodes` 的 `metadata.role` / `metadata.episode`、`production`、`drafts`）和 `backend` 里约定的几个方法（`sendTask`、`readExchange`、`stopBot`、`openChat`、`readConversation`、`fileUrl`、`readBotLooks`）。旧的 `CanvasNav`、`outline.ts`、`WaitingCard.tsx` 只参考、需要的照抄进自己的文件，不 import（`pb-board` 在替换那个文件夹）。看板本身由 `pb-board` 做，所以测试和预览用自己的样例快照和假 backend。

## 这一块定下的细节

### 面板

- 悬浮在右上角，宽 288，收起后只剩一个按钮。第一次打开时按浮层宽度决定：至少 900 宽就展开，否则收起；人点过以后照人的。
- 团队：负责人，然后按工作顺序（编剧、角色设计、场景设计，没有工作的成员在后），再按集（每集先分镜后后期）。全剧和分集两组。一行：头像、名字、头衔（每集的带 EP 码）、状态。点了：`focusNode(bot 节点)`，再 `open({ kind: "bot" })`。
- 素材分类：角色、场景、镜头（按集，每集一个可展开的行）、成片。点了：`focusNode`。
- 分集：每集一行，EP 码、标题、状态、已选用 / 镜头数；点了 `focusEpisode`。没有 `production` 的旧项目，`script` 节点当 EP01。
- 行是 memo 的，索引按快照算一次；60 集、约 130 个 bot 时只算一遍、只画当前那一栏。

### 对话窗

- 宽 400，放在卡片右侧，放不下就放左侧，再放不下夹在屏幕内；避开打开着的面板。跟 `subscribeView` 走，直接改 transform，不重新渲染。锚点为空时停在右上角（面板左边）；浮层窄于 720 时是底部抽屉。
- 往来用 `readExchange`，这个 bot 的状态、最新回复或等待的卡变了就重读；发完也重读。
- 参考托盘：`opened.references`、连入这个 bot 的节点（服务器本来就会带上，托盘里标"已连入"，不能去掉）、人从"添加参考"里挑的；分镜师默认带上全剧的角色卡和场景卡（不画线）。
- 现在的 `CanvasTaskRequest` 只会带上连入的节点。其余参考按"标签 + 标题 + 节点 id"一行一个写在任务文字后面，bot 用 `canvas_get_state` 按 id 读。需要 `pb-board` 给 `CanvasTaskRequest` 加 `references`（见状态文件）。
- Enter 发送（输入法组字时不发），Shift+Enter 换行；工作中或排队时有"停止"；"在聊天里打开"调 `openChat`。打开时读一次对话（`readConversation`），跟现在的面板一样。

### 素材详情

- 只读：类型、编号、标题、图片或视频（`fileUrl`）、属性（角色的标签和行、场景的副标题、镜头的景别 / 运镜 / 时长 / 声音、结果的版本、成片的剪映草稿状态）、提示词、出现在哪些镜头（点了换成那个镜头的详情）。
- 底部："在画布中定位"和"让 某某 调整"：负责它的 bot（角色 → 角色设计；场景 → 场景设计，分镜师细化出的归那位分镜师；镜头、结果 → 该集分镜师；成片 → 该集后期；分集 → 编剧；其他 → 负责人），`focusNode` 它的卡，再 `open({ kind: "bot", botId, references: [nodeId] })`。
