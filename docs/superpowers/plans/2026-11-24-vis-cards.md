# 看板卡片视觉对齐效果图（vis-cards）

目标：把 `src/components/production-board/cards/` 从「深色 UI 面板」改成效果图里的制作道具：纸张单据、监视器、图片主导的角色/场景、更高的智能体工位。

## 范围

- 自有：`cards/*`、`src/styles.css` 的看板令牌、`boardCards.*` 文案、`scripts/testing/board-cards-*`（尺寸同步）
- 不动：`board/chrome.tsx`、`BoardEdges.tsx`、`ProductionBoard.tsx`；效果图目录只读

## 步骤

1. `@theme` 增加跨皮肤固定的 `--color-board-*` 与 `--shadow-board`；注释说明纸张不随皮肤变。
2. `tone.ts`：`working` 点/字从 accent 改 warning（琥珀）。
3. `CardShell` 加 `surface?: "panel" | "paper" | "monitor"`；挂 `data-board-surface`。
4. `sizes.ts`：bot 320×420、character 380×200、scene 320×250、result 320×240、final 560×520、episodeStack 380×250；其余按需微调。
5. 逐卡照效果图改排版（Bot / Brief / Plan / Episode / Stack / Shot / Character / Scene / Result / Final）；不改数据模型。
6. DOM 测试先红后绿；新增 surface、对话按钮、打孔、SH 章、状态章等断言。
7. 四种语言补 `boardCards.*` 新键；不改 `source-hashes.json`。
8. 跑 tsc、lint、i18n、contrast、看板 DOM；截图双皮肤。

## 选择

- 圆角：panel 用 10px（效果图 `--r`）；monitor 用 `rounded-xl`；纸张 10px。
- 看板色走固定令牌，不进各皮肤块（纸就是纸）。
- 镜头卡本轮只做纸面排版，不加画框图。
