# 看板的卡片（pb-cards 轨道）

日期：2026-11-24 · 设计：`docs/superpowers/specs/2026-11-24-production-board-design.md` 第 4.1、4.4、8 节 · 章程：`OpenMausBot-wt/BOARD-CHARTER.md`

**目标：** 看板上每一种卡片做成只管显示的 React 组件，形态和内容照效果图 `index-v5`，颜色、字号、圆角和按钮用程序现有的主题变量和组件，深浅两套皮肤都对。`pb-board` 负责排版和接线，它从 `src/components/production-board/cards/index.ts` 取组件和 `BOARD_CARD_SIZES`。

## 做法

1. **尺寸和状态色**（`sizes.ts`、`tone.ts`）
   - `BOARD_CARD_SIZES`：每种卡片固定的宽高（看板像素），内容在卡内滚动或截断，不量 DOM。
   - 状态色只有五种：空闲、工作中、完成、等你、失败；bot、任务、分集的状态各有一个换算函数，远景标签和卡片共用。
2. **共用的零件**（`parts.tsx`）：卡片外壳（点卡片调 `onOpen`，卡里的按钮不冒泡）、状态点和文字、进度条、小按钮、bot 小头像、时间和时长的格式。
3. **卡片**，一种一个文件：
   - bot：现有的头像（`BotAvatar` + `CanvasBotLook`）、名字、头衔（每集的 bot 带 EP 码）、负责人的皇冠、状态（`CanvasBotStatus` 加任务状态）、当前任务、进度条和文字、最近几步（可选）、失败时“重试”、等人回答时的提示。
   - 需求单（标签 + 值）、任务拆分（T1…T5、负责的 bot、状态、并行标记）、分集（EP 码、标题、梗概或开头几行、状态、派给谁、失败时重试）、分集摞（“EP04 – EP60”、集数、前几集标题）。
   - 角色、场景（名字、标签或副标题、图、出场镜头；没图、生成中、失败；生成图片）、镜头（SH 码、标题、景别、运镜、时长、声音、引用的角色和场景小头像，只有文字）。
   - 结果（选用版本的画面或占位、版本数和 V1/V2 切换、选用、生成中不编数字、失败原因、生成或重新生成、卡内播放）、成片（封面或画面、时长、片段条、剪映草稿状态、在剪映里打开）、其他（文字、图片、视频）。
   - 远景标签：名字加状态色，按缩放反向放大，缩小时也看得清。
4. **文字**都在 `boardCards.` 下，英文、简体、繁体、巴西葡萄牙语各加在 `call.turns.oneMoment` 后面一处。
5. **测试**：每张卡一个 DOM 测试（内容、各状态、回调、长文本截断）。
6. **预览和截图**：`scripts/testing/board-cards-preview.tsx` 一页放下每张卡的每个状态（工作中、等你、完成、失败、生成中、还没图、长文本）；`board-cards-shots.ts` 在无头浏览器里截深浅两套皮肤、正常和窄窗口，放 `/tmp/omb-wt-pb-cards/`，占用界面夹具时按章程加锁，和效果图截图对比着改。

## 不碰的

看板本体、排版、浮层、侧栏、`shared/` 和服务器；需要快照多给的东西写进状态文件，由 `pb-board` 加。

## 顺序

尺寸、状态色、零件和文字 → 每张卡先写测试、看它因为该有的原因失败、再写代码 → 两小时内提交第一版并写进状态文件 → 预览和截图 → 对着效果图改 → 检查。
