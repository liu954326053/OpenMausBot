title: Usage analytics
description: MagicBot sends no usage analytics.
icon: ChartColumn
---

MagicBot sends no usage analytics. Nothing about how you use the app is counted or sent, to its makers, to PostHog or
to anyone else.

- MagicBot's own code contains no analytics library and no analytics key, and downloads none.
- The desktop app ships `cua-driver`, the program that lets bots use this computer. It has usage telemetry of its own,
  on unless switched off, and MagicBot always starts it switched off.
- Nothing is sent when the app starts, when you use a feature, or once a day: no install or launch count, no events, no
  daily summary of what is set up.
- Settings has no Usage analytics switch: there is nothing to turn off.
- When the desktop app crashes, it writes the crash to a log on this computer and sends nothing.

## After an update

The random id PostHog kept in the app's storage for an earlier version is never read or sent.

A MagicBot Cloud or self-hosted server serves the page of the version it runs. The desktop app cancels every request to
posthog.com and its subdomains, in every window, so a not-yet-updated server's page cannot send that earlier version's
analytics from the app; opened in a web browser, it still can until the server is updated.
