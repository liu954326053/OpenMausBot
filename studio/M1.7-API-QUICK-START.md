# M1.7 HTTP API 快速参考

## 启动服务

```bash
cd studio
pnpm install
pnpm build
PORT=8799 DATA_DIR=.data node dist/server/index.js
```

或在开发模式：
```bash
cd studio
pnpm dev  # 如果配置了 dev 脚本
```

## 项目管理

### 创建项目
```bash
curl -X POST http://localhost:8799/api/projects \
  -H "Content-Type: application/json" \
  -d '{
    "name": "我的第一部剧",
    "folder": "/projects/drama-001",
    "episodeCount": 12,
    "language": "zh",
    "teamSnapshotId": "tsn_abc123",
    "leadMode": "project-agent"
  }'
```

### 获取项目
```bash
curl http://localhost:8799/api/projects/prj_1234567890
```

### 列出项目
```bash
curl "http://localhost:8799/api/projects?limit=10&offset=0"
```

### 更新项目
```bash
curl -X PUT http://localhost:8799/api/projects/prj_1234567890 \
  -H "Content-Type: application/json" \
  -d '{
    "name": "我的第一部剧（修订版）",
    "episodeCount": 13
  }'
```

### 删除项目
```bash
curl -X DELETE http://localhost:8799/api/projects/prj_1234567890
```

  -H "Content-Type: application/json" \
  -d '{

```bash

```

```bash

  -H "Content-Type: application/json" \
  -d '{

    "completedAt": "2026-11-28T10:05:00Z",
    "exitCode": 0,
    "output": "生成成功"
  }'
```

## 实时事件

### 订阅事件（SSE）
```bash
# 在浏览器或支持 SSE 的客户端中
curl http://localhost:8799/api/events/stream/prj_1234567890

# Node.js 示例
const eventSource = new EventSource('http://localhost:8799/api/events/stream/prj_1234567890');
eventSource.onmessage = (event) => {
  console.log('Event:', JSON.parse(event.data));
};
```

### 获取事件历史
```bash
curl "http://localhost:8799/api/events/history/prj_1234567890?limit=50&offset=0"
```

### 发布事件
```bash
curl -X POST http://localhost:8799/api/events/publish \
  -H "Content-Type: application/json" \
  -d '{
    "type": "custom:event",
    "projectId": "prj_1234567890",
    "data": {
      "message": "自定义事件"
    }
  }'
```

## 错误处理

### 验证错误 (400)
```json
{
  "code": "VALIDATION_ERROR",
  "message": "Request validation failed",
  "statusCode": 400,
  "details": {
    "issues": [
      {
        "path": "name",
        "message": "String must contain at least 1 character(s)",
        "code": "too_small"
      }
    ]
  }
}
```

### 资源不存在 (404)
```json
{
  "code": "NOT_FOUND",
  "message": "Project prj_xxx not found",
  "statusCode": 404
}
```

### 服务器错误 (500)
```json
{
  "code": "INTERNAL_ERROR",
  "message": "An unexpected error occurred",
  "statusCode": 500
}
```

## 通用规则

| 规则 | 说明 |
|------|------|
| 分页 | `?limit=50&offset=0`（limit 最大 100） |
| 排序 | 通常按 `createdAt` 或 `updatedAt` DESC |
| ID 前缀 | `prj_` (项目), `art_` (产物), `tsk_` (任务), 等 |
| 时间戳 | ISO-8601 格式 (UTC): `2026-11-28T10:30:00Z` |
| 语言 | `zh` (中文) 或 `en` (英文) |
| 状态 | pending, running, completed, failed, cancelled |

## JavaScript 客户端示例

```typescript
class StudioAPI {
  constructor(baseURL = 'http://localhost:8799') {
    this.baseURL = baseURL;
  }

  async request(method: string, endpoint: string, body?: any) {
    const response = await fetch(`${this.baseURL}${endpoint}`, {
      method,
      headers: { 'Content-Type': 'application/json' },
      body: body ? JSON.stringify(body) : undefined,
    });
    
    if (!response.ok) {
      throw new Error(`HTTP ${response.status}: ${await response.text()}`);
    }
    
    return response.json();
  }

  // 项目
  createProject(data: any) {
    return this.request('POST', '/api/projects', data);
  }

  getProject(id: string) {
    return this.request('GET', `/api/projects/${id}`);
  }

  // 产物
  createArtifact(data: any) {
    return this.request('POST', '/api/artifacts', data);
  }

  createArtifactVersion(artifactId: string, content: string) {
    return this.request('POST', `/api/artifacts/${artifactId}/versions`, {
      content,
      format: 'text'
    });
  }

  // 对话
  createConversation(projectId: string, title: string) {
    return this.request('POST', '/api/conversation', {
      projectId,
      title,
      scope: 'drama'
    });
  }

  sendMessage(conversationId: string, content: string) {
    return this.request('POST', `/api/conversation/${conversationId}/messages`, {
      content,
      role: 'user'
    });
  }
}

// 使用
const api = new StudioAPI();
const project = await api.createProject({
  name: '我的第一部剧',
  folder: '/projects/drama-001',
  episodeCount: 12,
  language: 'zh',
  teamSnapshotId: 'tsn_123',
  leadMode: 'project-agent'
});
console.log(project.id);
```
