## 核心架构

### 1. 路由模块 (studio/src/server/routes/)

#### projects.ts - 项目管理
```
POST   /api/projects              创建项目
GET    /api/projects/:id          获取项目
PUT    /api/projects/:id          更新项目
DELETE /api/projects/:id          删除项目（逻辑删除）
GET    /api/projects              列出项目（分页）
```

**支持的操作**:
- 创建：name, folder, episodeCount, language, teamSnapshotId, leadMode
- 更新：name, episodeCount, language, maxConcurrentTasks, networkPerAgent
- 查询：limit/offset 分页

#### workflow.ts - 工作流图
```
GET    /api/workflow/:projectId/graph      获取工作流图
PUT    /api/workflow/:projectId/graph      更新工作流图
POST   /api/workflow/:projectId/validate   校验工作流图
```

**支持的操作**:
- 获取：返回当前工作流图（节点、边、元数据）
- 更新：更新图并创建版本事件
- 校验：检查节点连接性、孤立节点检测

#### artifacts.ts - 产物及版本管理
```
POST   /api/artifacts                       创建产物
GET    /api/artifacts/:id                   获取产物
PUT    /api/artifacts/:id                   更新产物
DELETE /api/artifacts/:id                   删除产物
GET    /api/artifacts/:id/versions          获取版本历史
POST   /api/artifacts/:id/versions          创建新版本
GET    /api/artifacts/:id/versions/:versionId   获取特定版本
```

**支持的操作**:
- 创建：type (source/brief/plan/script/episode/character/scene/shot/take/final), title, scope
- 版本：创建、列表、查询

#### tasks.ts - 任务管理
```
POST   /api/tasks                 创建任务
GET    /api/tasks/:id             获取任务
PUT    /api/tasks/:id/status      更新任务状态
GET    /api/tasks                 查询任务（过滤）
POST   /api/tasks/:id/attempts    记录执行尝试
```

**支持的操作**:
- 创建：name, nodeId, projectId, status
- 状态更新：pending → running → completed/failed/cancelled
- 执行记录：记录任务尝试、输出、错误信息

#### conversation.ts - 对话管理
```
POST   /api/conversation                   创建对话
GET    /api/conversation/:id               获取对话
PUT    /api/conversation/:id               更新对话
DELETE /api/conversation/:id               删除对话
POST   /api/conversation/:id/messages      发送消息
GET    /api/conversation/:id/messages      获取消息（分页）
```

**支持的操作**:
- 创建：title, description, scope (drama/episode)
- 消息：role (user/assistant/system), content, author
- 查询：limit/offset 分页

#### events.ts - SSE 实时事件流
```
GET    /api/events/stream/:projectId      订阅项目实时事件（SSE）
GET    /api/events/history/:projectId     获取事件历史
POST   /api/events/publish                发布事件
```

**支持的操作**:
- 订阅：WebSocket 长连接（SSE），心跳 30 秒
- 发布：发送事件到活跃订阅者
- 历史：查询事件日志（分页、类型过滤）

### 2. 中间件 (studio/src/server/middleware/)

#### error-handler.ts
```typescript
interface ApiError {
  statusCode: number;
  code: string;
  message: string;
  details?: Record<string, any>;
}
```

**处理**:
- ApiError：自定义错误
- ZodError：验证错误（详细字段信息）
- Error：通用异常

**状态码**:
- 400 - 验证错误
- 404 - 资源不存在
- 500 - 服务器错误

#### request-logger.ts
- 记录：方法、路径、状态码、响应时间、大小
- 格式：`[时间] METHOD PATH STATUS DURATIONms (SIZEb)`

### 3. 核心应用

#### app.ts - Express 应用
```typescript
createApp(context: AppContext): Express
  ├─ Middleware
  │  ├─ express.json()
  │  └─ requestLogger
  ├─ Routes
  │  ├─ /api/projects → projectRouter
  │  ├─ /api/workflow → workflowRouter
  │  ├─ /api/artifacts → artifactsRouter
  │  ├─ /api/tasks → tasksRouter
  │  ├─ /api/conversation → conversationRouter
  │  └─ /api/events → eventsRouter
  ├─ Health Check
  │  └─ GET /api/health
  └─ Error Handler → errorHandler
```

#### index.ts - 服务器启动
- 初始化数据库
- 创建 Express 应用
- 监听端口（默认 8799）
- 优雅关闭处理

## 数据库集成

### 扩展的仓库方法

#### ProjectRepository
- `list(options)` - 分页列表查询
- 支持 `limit`, `offset`, `includeDeleted`

#### ArtifactRepository
- `createVersion(data)` - 创建产物版本
- `getVersion(versionId)` - 获取版本
- `listVersions(artifactId)` - 列出版本
- `update(id, data)` - 更新产物元数据

#### TaskRepository
- `list(options)` - 查询任务（过滤）
- `updateStatus(id, data)` - 更新任务状态
- 支持 projectId, status 过滤

#### EventRepository（简化版）
- `create(data)` - 创建事件
- `listByProject(projectId, options)` - 查询项目事件
- `createConversation(data)` - 创建对话
- `getConversation(id)` - 获取对话
- `getConversationMessages(id)` - 获取消息
- `deleteConversation(id)` - 删除对话
- `getWorkflowGraph(projectId)` - 获取工作流图

## 验证机制

### Zod 架构
- 请求体验证：所有 POST/PUT 操作
- 自动转换：字符串 → 枚举、数字等
- 错误报告：详细的字段级错误

### 验证示例
```typescript
const createProjectSchema = z.object({
  name: z.string().min(1).max(255),
  folder: z.string().min(1),
  episodeCount: z.number().int().min(1),
  language: z.enum(['zh', 'en']),
  teamSnapshotId: z.string(),
  leadMode: z.enum(['project-agent', 'main-agent']),
});
```

**验证失败响应**:
```json
{
  "code": "VALIDATION_ERROR",
  "message": "Request validation failed",
  "statusCode": 400,
  "details": {
    "issues": [
      {
        "path": "name",
        "message": "String must contain at least 1 character(s)",
        "code": "too_small"
      }
    ]
  }
}
```
