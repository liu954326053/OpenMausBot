## Key Features Implemented

### 1. ✅ Streaming Support

- **Token-level emission**: Each token yielded immediately
- **Non-blocking**: Caller processes events as they arrive
- **Tool call streaming**: Incremental argument assembly from SSE chunks
- **Multiple event types**: tokens, tool_calls, tool_results, completion

### 2. ✅ Tool Execution & Permissions

- **Registry lookup**: O(1) tool discovery
- **Permission enforcement**: Calls `checkPermission()` before execution
- **Error handling**: Graceful degradation on permission denied or not found
- **Disabled tools**: Skips execution with error message
- **Tool results**: Properly formatted and appended to history

### 3. ✅ Conversation Management

- **History tracking**: Maintains full message history
- **Tool results integration**: Appends tool results with proper role ("user" with tool_call_id)
- **System message preservation**: Always keeps system prompts regardless of context
- **Assistant message construction**: Builds proper assistant messages with tool_calls array

### 4. ✅ Context Clipping

- **Sliding window strategy**: Keeps most recent messages
- **Token estimation**: Character-based heuristic (configurable)
- **System message priority**: Never clips system prompts
- **Graceful degradation**: Shortens history instead of failing

### 5. ✅ Resilience

- **Abort signal support**: Respects caller's AbortController
- **Timeout infrastructure**: Propagates timeouts through pipeline
- **Max iterations**: Prevents infinite loops (configurable, default 10)
- **Error events**: Emits errors without crashing
- **Error types**: Token, tool_call, tool_result, engine errors all handled

### 6. ✅ Protocol Compliance

- **OpenAI-compatible format**: Tool calls follow spec
- **Stop reasons**: Handles "stop_sequence" and "tool_calls"
- **Message roles**: Proper "user", "assistant", "system", "tool" role handling
- **Tool call structure**: Follows OpenAI function_calling format

## Known Limitations & Future Work

### Current Limitations

1. **Token estimation**: Uses character heuristic, not actual tokenizer
2. **Memory accumulation**: Full assistant message buffered in memory
3. **Sequential tool calls**: Executes tools one at a time (no parallelism)
4. **No result filtering**: All tool results sent to LLM (privacy concern for some)

### Future Enhancements

1. **Function result streaming**: Support streaming outputs from tools
2. **Parallel execution**: Execute independent tool calls concurrently
3. **Actual tokenization**: Use real tokenizer (e.g., js-tiktoken)
4. **Result filtering**: Redact sensitive outputs before LLM
5. **Chain-of-thought**: Support reasoning tokens and intermediate steps
6. **Multi-agent routing**: Route between different agent endpoints
7. **Prompt caching**: Reuse expensive system prompts
8. **Observability**: Add structured logging and tracing

## How to Use

### Quick Start

```typescript
import { AgentLoop } from "studio/server/runtime/loop/index.ts";
import { OpenAICompatibleClient } from "studio/server/runtime/loop/index.ts";
import { ToolRegistry } from "studio/src/service/runtime/tools/index.ts";

// 1. Setup engine
const engine = new OpenAICompatibleClient({
  baseURL: "https://api.openai.com",
  apiKey: process.env.OPENAI_API_KEY,
  model: "gpt-4",
});

// 2. Setup tools
const toolRegistry = new ToolRegistry();
toolRegistry.register({
  name: "search",
  description: "Search the web",
  schema: { /* ... */ },
  execute: async (params) => {
    return await mySearchFunction(params.query);
  },
});

// 3. Create loop
const loop = new AgentLoop(engine, toolRegistry);

// 4. Run conversation
const messages = [
  { role: "user", content: "Search for TypeScript best practices" }
];

for await (const event of loop.run({ messages })) {
  switch (event.type) {
    case "token":
      process.stdout.write((event.data as any).text);
      break;
    case "tool_call":
      console.log(`\nCalling: ${(event.data as any).name}`);
      break;
    case "complete":
      console.log("\n✓ Done");
      break;
  }
}
```

### Configuration

```typescript
const loop = new AgentLoop(engine, toolRegistry, {
  maxIterations: 15,           // Allow more iterations
  maxContextTokens: 64000,     // Smaller context window
  tokensPerCharacter: 0.3,     // Adjust heuristic
  defaultSystemPrompt: "You are helpful...",
});
```

### Abort & Timeout

```typescript
const abortController = new AbortController();

// Abort after 30 seconds
setTimeout(() => abortController.abort(), 30000);

for await (const event of loop.run({
  messages,
  signal: abortController.signal,
  timeoutMs: 30000,
})) {
  // ...
}
```
